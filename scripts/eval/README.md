# scripts/eval — доказательная база замеров

Скрипты, которыми получены числа в [`docs/RECALL85.md`](../../docs/RECALL85.md).
Раньше они лежали в `scratch/`, который не под git, — то есть документ ссылался
на воспроизведение, невозможное после клона. Это исправлено: сами скрипты
в репозитории, кэши остаются в `scratch/out/` (они большие и машинозависимые).

Запускаются из корня проекта: `npx tsx scripts/eval/<имя>.mts`.

| скрипт | что меряет |
|---|---|
| `gap-analysis.mts` | корзинная разборка рангов ожидаемого ответа |
| `hnsw-recall.mts` | пересечение приближённой выдачи с точным перебором |
| `hnsw-debug.mts` | разбор конкретного запроса, где HNSW теряет кластер |
| `cascade.mts` | свип глубины и режимов слияния cross-encoder |
| `qx.mts` | мульти-представление запроса: base / kw / hydeQ / hydeD / lex |
| `qx-subsets.mts` | все 31 сочетание ветвей: RRF и доступность |
| `qx-depth.mts` | кривая «глубина ↔ размер union ↔ качество» при единой глубине |
| `qx-unique.mts` | уникальный вклад каждой ветви и значимость разницы |
| `qx-window.mts` | сколько ответов доходит до окна судьи |
| `qx-marginal.mts` | поимённо запросы, недостижимые сокращённым union |
| `stage0.mts` | пайплайн без `@deleted` |
| `stage2.mts` / `stage2b.mts` / `stage2c.mts` | вторая ступень: CE, судья, каскад |
| `stage3.mts` | судья с описаниями в карточках (замерен и отклонён) |
| `desc-gen.mts` / `desc-eval.mts` | генерация описаний назначения и ранжирование по ним |
| `deadprobe.mts` | запросы, недостижимые при любом представлении |

**Что нужно поднять:** PostgreSQL с индексом, эмбеддер (`npm run embed`),
реранкер (`npm run rerank:gpu`). Для скриптов с LLM — ollama с `gemma3:latest`
и `qwen3-vl:8b`; они относятся к исследовательской ветке (RECALL85 §4.1),
в продовом поиске генеративных моделей нет.

**Кэши.** Все выводы моделей кэшируются в `scratch/out/*.json`, поэтому повторный
прогон бесплатен, а часть выводов проверяется вообще без моделей — например,
арифметика мульти-представления:

```bash
node -e "const r=require('./scratch/out/qx-gemma3_latest.json').ranks; \
for (const k of [5,10,20,30,50,300]) \
console.log(k, r.oracle.filter(x => x !== null && x <= k).length)"
# ожидается: 35 42 45 48 52 54
```
